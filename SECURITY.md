# Security

AI Context Hub processes private conversation history. Treat every local vault,
browser snapshot, database, export, token, and log as sensitive.

## Never commit

- `local-vault/`
- `exports/`
- `extension/config.local.js`
- `.env` files
- API keys, cookies, authorization headers, or private keys

## Reporting

Please report security issues privately to the repository owner rather than
opening a public issue with real conversation data or credentials.
